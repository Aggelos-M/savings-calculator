savings-calculator.
Μικρή web εφαρμογή σε Python (Streamlit) που υπολογίζει πόσες ώρες εργασίας και πόσα χρήματα εξοικονομούνται με εναν AI VOICE AGENT.

WEBSITE LINK:
https://savings-calculator-dvza88agjou9cvjelhsshd.streamlit.app



 Τι υπολογίζει:

 κλήσεις ανά ημέρα, μέση διάρκεια κλήσης (λεπτά), ωριαίο κόστος
υπαλλήλου (€), ποσοστό κλήσεων του agent (%), εργάσιμες ημέρες ανά μήνα
, και προαιρετικά μηνιαίο κόστος agent.

Αποτέλεσμα: ώρες που εξοικονομούνται τον μήνα, μηνιαία και ετήσια εξοικονόμηση
σε ευρώ, και γράφημα κόστους πριν/μετά τον agent.
