SAVINGS-CALCULATOR.
Μικρή εφαρμογή σε Streamlit που υπολογίζει πόσες ώρες εργασίας και πόσα χρήματα εξοικονομεί μια εταιρεία χρησιμοποιώντας έναν AI Voice Agent, με βάση:

τον αριθμό κλήσεων ανά ημέρα
τη μέση διάρκεια κλήσης (λεπτά)
το ωριαίο κόστος υπαλλήλου (€)
το ποσοστό κλήσεων που αναλαμβάνει ο agent (%)
τις εργάσιμες ημέρες ανά μήνα (προεπιλογή 22)
το μηνιαίο κόστος συνδρομής του agent (€, προαιρετικό)
