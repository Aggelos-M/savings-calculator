# Savings-Calculator (AI Voice Agent)

Διαδραστική διαδικτυακή εφαρμογή σε Python (**Streamlit**) για τον υπολογισμό της εξοικονόμησης χρόνου και χρημάτων από την ενσωχάτωση ενός AI Voice Agent στην εξυπηρέτηση πελατών και τη διαχείριση κλήσεων μιας επιχείρησης.
## 🌐 Live Εφαρμογή
https://savings-calculator-dvza88agjou9cvjelhsshd.streamlit.app/

## 🚀 Κύριες Λειτουργίες & Χαρακτηριστικά
- **Υπολογισμός Εξοικονόμησης:** Υπολογίζει τις καθαρές ώρες που εξοικονομούνται μηνιαίως, καθώς και την ακαθάριστη και καθαρή εξοικονόμηση σε ευρώ (μηνιαία και ετήσια βάση).
- **Προηγμένα Στοιχεία Κόστους Agent:**
  - Μηνιαίο πάγιο κόστος (€).
  - Χρέωση ανά λεπτό χρήσης (€/λεπτό).
  - Χρόνος ανθρώπινου ελέγχου ανά κλήση (λεπτά).
  - Εφάπαξ κόστος εγκατάστασης (€).
- **Ανάλυση Σεναρίων:** Συγκριτική αξιολόγηση τριών διαφορετικών σεναρίων (Συντηρητικό, Βασικό, Αισιόδοξο) με ξεχωριστό ποσοστό ανάληψης κλήσεων.
- **Οικονομικοί Δείκτες:**
  - **Όριο Οικονομικής Ισορροπίας (Breakeven Percentage):** Βρίσκει το ελάχιστο ποσοστό ανάληψης κλήσεων ώστε το καθαρό αποτέλεσμα να είναι μεγαλύτερο ή ίσο του μηδενός.
  - **Απόδοση Επένδυσης (ROI Πρώτου Έτους):** Υπολογίζει το ποσοστό απόδοσης της επένδυσης λαμβάνοντας υπόψη όλα τα κόστη και το εφάπαξ ποσό εγκατάστασης.
- **Δωδεκάμηνη Προβολή & Γραφήματα:** Σωρευτική απεικόνιση του καθαρού αποτελέσματος για τους πρώτους 12 μήνες λειτουργίας και συγκριτικό γράφημα κόστους πριν/μετά τον agent.
- **Εξαγωγή Δεδομένων (CSV):** Δυνατότητα λήψης των αναλυτικών αποτελεσμάτων και των ενδιάμεσων υπολογισμών σε αρχείο CSV με σωστή κωδικοποίηση για ελληνικούς χαρακτήρες.



## 📐 Βασικές Παραδοχές & Μαθηματικοί Τύποι
1. **Μηνιαίες Ώρες Εργασίας (χωρίς agent):**
   $$\text{Hours/Month} = \frac{\text{Calls/Day} \times \text{Avg Duration} \times \text{Working Days}}{60}€
2. **Καθαρές Εξοικονομούμενες Ώρες:**
   Από τις ακαθάριστες ώρες του agent αφαιρείται ο χρόνος που απαιτείται για τον ανθρώπινο έλεγχο (€ λεπτά ανά κλήση agent).
3. **Καθαρό Μηνιαίο Αποτέλεσμα:**
   $$\text{Net Monthly} = \text{Gross Savings} - F - \text{Usage Cost}€
   *(όπου $F$ είναι το μηνιαίο πάγιο και Usage Cost το κόστος χρήσης ανά λεπτό)*.
4. **ROI Πρώτου Έτους:**
   €\text{ROI} = \frac{\text{Net First Year}}{\text{Total Agent Cost First Year}} \times 100€.
