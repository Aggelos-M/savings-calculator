# Savings-Calculator

Μικρή web εφαρμογή σε Python (Streamlit) που υπολογίζει πόσες ώρες εργασίας και
πόσα χρήματα εξοικονομούνται με έναν AI Voice Agent.

## Τι υπολογίζει

Δεδομένα εισόδου: κλήσεις ανά ημέρα, μέση διάρκεια κλήσης (λεπτά), ωριαίο κόστος
υπαλλήλου (€), ποσοστό κλήσεων που αναλαμβάνει ο agent (%) και εργάσιμες ημέρες
ανά μήνα.

Αποτέλεσμα: ώρες που εξοικονομούνται τον μήνα, μηνιαία και ετήσια εξοικονόμηση
σε ευρώ, και γράφημα κόστους πριν/μετά τον agent.επίσης υπολογίζει το μηνιαιο κοστος του agent,της χρεώσης του agent αν λεπτό/ά της κλήσης σε ευρώ,Χρόνος ανθρώπινου ελέγχου ανά κλήση agent (λεπτά),Εφάπαξ κόστος εγκατάστασης (€),Συντηρητικό σενάριο — ποσοστό ανάληψης (%),Βασικό σενάριο — ποσοστό ανάληψης (%),Αισιόδοξο σενάριο — ποσοστό ανάληψης (%).

## Απαιτήσεις

- Python 3.9 ή νεότερο

  Εγκαταστήστε τις βιβλιοθήκες:

   bash
   pip install -r requirements.txt
   

## Τοπική εκτέλεση

Από τον φάκελο του project τρέξτε:

bash
streamlit run app.py


Η εφαρμογή ανοίγει αυτόματα στον browser, συνήθως στη διεύθυνση
`http://localhost:8501`. Αν δεν ανοίξει μόνη της, αντιγράψτε τη διεύθυνση που
εμφανίζεται στο terminal. Για να σταματήσετε την εφαρμογή, πατήστε `Ctrl + C`
στο terminal.
